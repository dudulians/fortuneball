# Fortune Ball

Шар предсказаний для iPhone: задай вопрос, встряхни телефон (или коснись шара) — ответ всплывёт сквозь жидкость в синем окошке.

План развития и решения по продукту — в [PLAN.md](PLAN.md).

## Что внутри

- **React + Vite + TypeScript**, обычный CSS без библиотек.
- **Capacitor 8**: `@capacitor/motion` (тряска и наклон), `@capacitor/haptics` (вибрация),
  `@capacitor/share` + `@capacitor/filesystem` (карточка для сторис), `@capacitor/splash-screen`.
- Шар — фотореалистичные рендеры `public/ball-idle.webp` и `public/ball-answer.webp`
  (вырезаны из PNG скриптом `node scripts/cut-ball.mjs`). Живое только окно с жидкостью
  и всплывающим кубиком, оно лежит точно поверх окна рендера. Блик едет за наклоном телефона.
- Текст на грани: один размер шрифта для всех ответов языка, подобранный по самому длинному
  (`src/fitText.ts`, измеряет реальную ширину букв и учитывает сужение треугольника).
  Поэтому ответы короткие: верхняя строка ≤ 9 знаков, вторая ≤ 7, третья ≤ 5 —
  один длинный ответ уменьшит шрифт у всех. В режиме разработки в консоли есть
  `__fortune.setAnswer("p05")` и `__fortune.setLang("ru")`, чтобы проверить любой ответ без случайности.
- **Окно шара рисуется в WebGL** (`src/liquid/`): тёмная почти непрозрачная жидкость без узоров,
  настоящий двадцатигранник с ответом на каждой грани (грань i = ответ i), который кувыркается
  при тряске и всплывает нужной гранью к стеклу (в глубине он тусклый и размытый),
  мягкое блуждающее пятно света, крошечные пузырьки, тёмные силуэты кубика при тряске,
  стекло с бликом по наклону. Если WebGL недоступен, показывается CSS-окно
  (`.facet-*`, `.die-*` в `App.css`) — оно остаётся как запасной вариант.
  В режиме разработки есть `__liquid.render({rise, churn, time, bubbles, steps})`, чтобы отрисовать
  кадры вручную (каждый шаг = ровно один кадр 60 fps), и `__liquid.state()` — угол между кубиком
  и его положением покоя плюс остаточное вращение, чтобы численно проверять плавность укладки.
- Грань кубика занимает 70% ширины окна (верх на 24% высоты) и плавает в жидкости, как на настоящем
  шаре. Меняя геометрию, правь все три места: `.die` в `App.css`, `W`/`faceCenter` в
  `liquid/shaders.ts`, `drawWindow` в `shareCard.ts`.
- **Один шрифт на всё приложение** — Manrope (вшит через `@fontsource`, есть кириллица).
  Иерархия только размером, весом и разрядкой. На кубике тот же Manrope, жирные капители.
- Под полем вопроса крутятся примеры вопросов (`src/examples.ts`, по 24 на язык): тап по примеру
  вставляет его в поле, кнопка ↻ показывает следующий.
- Звук процедурный (Web Audio): приглушённые удары кубика о стекло и «бульк» всплытия.
- 20 ответов на EN и RU в [src/answers.ts](src/answers.ts). Язык берётся из телефона, меняется в настройках.
- Вопросы с текстом сохраняются в историю (`localStorage`, ключ `fortuneball.history.v1`) — база для фишки «Сбылось?».
- Вопрос можно сказать голосом: кнопка микрофона у поля (`src/speech.ts`,
  плагин `@capacitor-community/speech-recognition`, системное распознавание iPhone, EN/RU).
  Замолчала → через полторы секунды запись останавливается и шар трясётся сам.
  В браузере работает через Web Speech API (Chrome), если микрофон разрешён.

## Что можно подкрутить

В [src/App.tsx](src/App.tsx):
- `SHAKE_MS = 1300` — сколько шар трясётся.
- `RISE_MS = 1150` — сколько кубик всплывает.

В [src/motion.ts](src/motion.ts), функция `listenForShake` (тряска длится, пока трясут;
каждый толчок = вибрация + стук + качок):
- `threshold: 16` — чувствительность. Срабатывает от ходьбы — поставь 20. Надо трясти как бешеный — поставь 12.
- `quietMs: 450` — через сколько тишины после последнего толчка тряска считается законченной.
- В [src/App.tsx](src/App.tsx): `MIN_SHAKE_MS = 900` и `MAX_SHAKE_MS = 8000` — рамки длительности.
